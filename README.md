# Shark Life

Sistema operativo de vida (PWA): áreas de vida, IKIGAI, DOFA, sueños y metas, tareas, hábitos, finanzas y patrimonio.
Next.js 14 + Supabase, desplegado en Vercel.

> Nombre provisional — ver `docs/PENDIENTES.md` → MARCA-01.

## Empezar

```bash
npm install
cp .env.example .env.local   # completar
npm run dev
```
